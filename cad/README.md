# CAD design bank

3D-printable experimental components. All models were designed with Autodesk
Fusion 360 and printed on a Bambu Lab X1E.

**License: CC BY 4.0** (https://creativecommons.org/licenses/by/4.0/).
You may share and adapt these models, including commercially, with attribution
to the paper (see repository README).

Each component directory should contain three formats:

| Format | Purpose |
|---|---|
| `.f3d` | Editable Fusion 360 source — modify dimensions for your own setup |
| `.step` | Neutral exchange format for other CAD software |
| `.stl` | Ready to slice and print |

## Components

| Directory | Component |
|---|---|
| `robot-arm-holder/` | Holder fixing the robot arm |
| `pipette-holder/` | Holder fixing the electric pipette to the robot arm tip |
| `balance-cover/` | Liquid-splash cover for the electronic balance (with windshield) |
| `imaging-stand/` | Holding stand for the appearance-imaging system (light, sample, camera) |
